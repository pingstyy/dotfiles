                   "selfatn" -> "Self_Attention_Score" (if in LSP/buffer)

                   Needs the symbol to already exist OR use Case variants

RUN (pane auto-closes on insert / search / visual / move / picker / other pane)
Space r r          if this project has steps → run them in order (joined &&)
                   else save + run current file (filetype default)
                   focus STAYS in editor; first key/click in editor HIDES pane
Space r l          re-run the exact last command string
Space r t          toggle output pane (also auto-hides on next editor action)
Space r e          edit sequential steps (one cmd per line). :w save
Space r a          add one step (prompt). delete a line in Space r e to remove
Space t t          free interactive shell (toggleterm, current file dir)
Ctrl-\             toggle float terminal (interactive)
Esc                leave terminal mode → normal mode
Pipeline           per git-root (or cwd). # comments + blank lines skipped
                   example:
                     make build
                     cd build
                     ./filerun
                     xprof ./fileout
                   →  make build && cd build && ./filerun && xprof ./fileout
                   fail in a step stops the rest (that's &&). use `;` in a line
                   if that step must not abort the chain.
                   empty file = Space r r falls back to current-file run
Filetype cmds      python→conda/venv python; go→go run; rust→cargo run;
                   js/ts→node/tsx; c/cpp→compile+run; sh→bash/zsh; …
Python env         current conda/venv, else last pick (modal-env etc)
                   :PythonSelectEnv  pick   :PythonShowEnv  show
                   iron + runner + new tmux panes all use this env

Ghostty / Mac NOTE (Cmd keys)
Ghostty DEFAULTS steal keys before Neovim:
  Cmd+Enter  = toggle_fullscreen   → unbound in ghostty config
  Cmd+1..9/0 = goto_tab            → unbound (nvim file tabs)
  Cmd+w      = close_surface       → unbound (nvim close file tab)
Config: ~/Library/Application Support/com.mitchellh.ghostty/config
Reload: Cmd+Shift+,  (or restart Ghostty)
Fullscreen now: Cmd+Ctrl+F
Option-as-Meta: macos-option-as-alt=left  → use LEFT Option for Opt+N
If Cmd+N still does nothing:  ghostty +list-keybinds | rg 'super\+(enter|[1-9])'
