SP4SS NEOVIM CHEATSHEET
Leader: Space

DASHBOARD
n                  shell: open Neovim dashboard
c                  dashboard: open config picker
n                  dashboard: new buffer
q                  dashboard: quit
:Cheat / :cheat    open this file

COMPLETION / SNIPPETS
Tab                next completion / next snippet placeholder
Shift-Tab          previous completion / previous snippet placeholder
Enter              accept selected completion
Option-Enter       accept completion and insert newline
Option-Space       show completion + docs
Cmd-1..9           accept dropdown item 1..9 (GUI / Neovide)
Option-1..9        accept dropdown item 1..9 (terminal-friendly fallback)
Option-j/k         scroll completion docs
Fuzzy match        case-insensitive; skips typos
                   "selfatn" -> "Self_attention_score"
                   "self-attention-xxx" -> "Self_Attention_Xxx"
                   "_" and "-" treated interchangeably when matching
:SnippetEdit       edit snippets for current filetype
:SnippetEdit lua   edit snippets for a filetype
:SnippetPackage    edit snippets/package.json
:SnippetCheck rafc check if custom snippet prefix exists
Snippet files      ~/.config/nvim/snippets/*.json

COMMENTING (language-aware via commentstring)
Ctrl-/             toggle comment line / visual selection (terminal)
Ctrl-_             same (many Mac terminals send C-/ as C-_)
Cmd-/              toggle comment (GUI only; terminal often swallows Cmd)
Visual + above     comment/uncomment all selected lines
Note               uses Neovim built-in gc/gcc (// # -- etc by filetype)

PATHS / REGISTERS
"%p                paste current relative file path in normal mode
Ctrl-r %           paste current relative file path in insert mode

Space y p          copy absolute file path

Space y c          copy cwd
:Registers         registers picker

MAC KEY NOTES
Cmd often never reaches terminal Neovim (Terminal.app / iTerm swallow it).
Prefer Option-1..9 and Ctrl-/ in the terminal; Cmd-* works in GUI clients.
