Ghostty / Mac NOTE
Ctrl+letter        reaches Neovim. Ghostty does not bind Ctrl+h/j/k/l/w.
Ctrl+Tab           Ghostty next terminal tab (Ctrl+Shift+Tab = previous)
Cmd is Ghostty's window modifier. These defaults are unbound so Neovim gets them:
  Cmd+Enter  fullscreen → unbound. Fullscreen is Cmd+Ctrl+F
  Cmd+1..9/0 tabs / font reset → unbound (nvim Harpoon 1..10)
  Cmd+w      close surface → unbound
Window splits      backtick, then v/h/arrows (not Ctrl)
Config: ~/Library/Application Support/com.mitchellh.ghostty/config
Reload: Cmd+Shift+,  (or restart Ghostty)
Option-as-Meta: macos-option-as-alt=left  → use LEFT Option for Opt+N
If Cmd+N still does nothing:  ghostty +list-keybinds | rg 'super\+(enter|[1-9])'

--- mini.diff (replaces gitsigns) ---
gh = apply hunk (visual/operator) | ghip = apply paragraph
gH = reset hunk | gHip = reset paragraph
gh = textobject hunk range (dgh = delete hunk)
[H [h ]h ]H = first/prev/next/last hunk
Space gd = toggle overlay (shows deleted lines as virtual text)
Space gt = toggle diff ON/OFF per buffer (thin gutter: green add=▎ yellow change=▎ red delete=▁)

--- trouble.nvim ---
<leader>xx = toggle diagnostics (all) | same key again = OFF
<leader>xX = toggle buffer diagnostics only
<leader>xs = toggle symbols (right)
<leader>xl = toggle loclist
<leader>xq = toggle quickfix
<leader>xt = force OFF / close Trouble
q / <esc> inside trouble = close
